# Harvard-Oxford subcortical Parcellation

This parcellation file is named `atlas-HarvOxfSub_nparc-21_space-MNI_res-2x2x2.nii.gz`. It was previously named `HarvardOxford-sub-prob-bin-2mm.nii.gz` in osl-ephys.

It is the Harvard-Oxford subcortical probabilistic atlas distributed with FSL (`HarvardOxford-sub-prob-2mm`), thresholded at 50% and binarised, with the 21 structures in FSL's order. It includes the cerebral white matter, cortex and ventricles of each hemisphere, which are usually excluded when parcellating M/EEG data (see [schaeferharvoxf114.md](schaeferharvoxf114.md) for the 14 structures combined with a cortical parcellation).
